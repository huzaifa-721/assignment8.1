 I built a basic dashboard using CSS Grid as per the requirements. For the dashboard header, I created a top bar containing the title Analytics Dashboard on the left and a search input and user avatar on the right side, styled with flexbox inside for alignment. I created a sidebar on the left containing a logo and navigation links like Dashboard, Users, Products, Sales, Reports, and Settings, with a dark background and active states, and a main content area on the right which holds all the statistics and charts. In the main content area, I added four statistic cards showing Total Users with 12,543 count, Revenue with $84,200, Orders with 1,234, and Conversion with 3.24%, each with a colored left border and growth percentage, and below that I added a sales overview chart area and recent activity list. For the outer layout, I used display grid on the main dashboard container, which is the parent of header, sidebar, and main content, and I set grid-template-columns to 240px 1fr meaning sidebar takes 240px fixed and main takes remaining space, and grid-template-rows to 70px 1fr meaning header is 70px fixed height, and I used grid-template-areas to name the layout as sidebar header on first row and sidebar main on second row for better readability and easier placement. For gaps between cards, I used gap 20px in the stats-grid which creates equal spacing between all four cards both horizontally and vertically without using margins, and also used gap 20px in the content-grid for chart and activity boxes. I inspected the grid layout in the browser using Chrome DevTools Grid overlay which shows column lines, row lines, and gaps clearly, and I tested responsiveness: on desktop the sidebar is on left and 4 cards in a row, on tablet 2 cards in a row, and on mobile sidebar moves to top and cards stack vertically in one column, demonstrating how Grid makes dashboard layouts very easy compared to floats or Flexbox.Screenshot for Submission:Desktop — Open DevTools > Elements > click grid badge on .dashboard and .stats-grid to show grid lines + gapsTake one desktop (1200px) and one mobile (400px) screenshot
